# tebscribe.com SEO audit, 2026-11-04

Scope: every HTML page in the repo (22), compared byte for byte with the live site on 2026-11-04. All 22 pages, `robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt`, the IndexNow key file, `tb-beacon.js`, `tb-consent.js`, `tb-nav.js`, `i18n-tebscribe.js`, `3d/tebscribe-3d.js` and `assets/og-image.png` were identical to the repo at the start. Nothing is committed or deployed; the fixes below are in the working tree only.

What was not measured: no Search Console or Bing Webmaster data was available, no PageSpeed or field Core Web Vitals run was done, and no ranking data was pulled. Sizes below are real file sizes; speed statements are risks read from the code, not timings.

## 1. Summary

The site is crawlable and clean at the basics: every page returns 200, http redirects to https with a 301, www redirects to the apex, unknown paths return a real 404, every page has one H1, a canonical and no image without alt text, and the sitemap already listed every indexable page and none of the noindex ones. The problems were about what the homepage says and how consistently the pages describe themselves.

Top issues, in order of impact:

1. **The homepage had almost no crawlable body copy.** It is a scroll-driven 3D tour. The only keyword text (an "About this page" block with the FAQ) was clipped to 1 pixel whenever the 3D tour was running (`3d/tebscribe-3d.js:4117`, rule `html.j3d-on .j3d-more`). Fixed: a visible overview and FAQ now exist (section 4).
2. **Homepage title (81 characters) and description (198) were too long**, so Google would cut both. Fixed (61 and 158).
3. **A WebPage JSON-LD block pointed at `https://tebscribe.com/3d/`** (`@id` and `url`) while the canonical is `https://tebscribe.com/`. It declared a page that is noindex as the identity of the homepage. Fixed.
4. **Organization data disagreed between pages**: five, six or seven `sameAs` entries depending on the page, and the same app (tebDictate) had two different `@id` values. Fixed: one Organization node, eight `sameAs` entries (including the tebIQ Google Play listing), shared `@id` values.
5. **Locale variants are not crawlable URLs** (section 5). This is a structural limit, not a bug.
6. **Outbound links to the product sites had no campaign tags, and the beacon was missing on three indexable pages.** Fixed (section 7).

## 3. Crawl and index controls

- **robots.txt.** Before: seven groups, fully permissive. After: 23 groups, all `Allow: /`, no `Disallow` anywhere. Tokens checked against each operator's own documentation on 2026-11-04: Googlebot, Googlebot-Image, Googlebot-Video (Google common crawlers page); Bingbot (Bing); Applebot and Applebot-Extended (Apple support page 119829); DuckDuckBot; YandexBot; Google-Extended; GPTBot, OAI-SearchBot, ChatGPT-User (OpenAI bots page); ClaudeBot, Claude-User, Claude-SearchBot (Anthropic support article 8896518); PerplexityBot, Perplexity-User (Perplexity docs); Meta-ExternalAgent (Meta crawler docs); CCBot (Common Crawl); Amazonbot (Amazon); MistralAI-User (Mistral docs). Google-Extended and Applebot-Extended are control tokens (they decide whether crawled content may be used for AI), not separate crawlers.
- **YouTube / Google video.** There is no YouTube crawler to allow. Google video indexing uses Googlebot-Video, which is now listed. The site has no `<video>`, no embed and no YouTube link anywhere, so no VideoObject markup was added (it must describe a real video). When there is a channel, add its URL to `Organization.sameAs` on every page and to `llms.txt`. Any embedded video later needs a real `VideoObject` (name, description, thumbnailUrl, uploadDate) and a transcript on the page.
- **noindex pages** (`/3d/`, `/classic.html`, `/bellody/classic.html`, `/tebcapture/`, `/404.html`) are correctly absent from the sitemap and correctly not blocked in robots.txt (a crawler must fetch a page to see its noindex).
- **Sitemap.** Before: 17 URLs, complete, lastmod set by hand and stale (for example the homepage said 2026-10-16). After: 17 URLs, still complete, generated by `node tests/gen-sitemap.mjs --write` (lastmod is the git commit date, or the day of the run for uncommitted files). A test now fails if an indexable page is missing or a noindex page is listed. No `hreflang` entries because no locale URLs exist.
- **Orphans.** No indexable page is an orphan. `/3d/` and `/classic.html` have no inbound links, which is intended. The least linked indexable pages were `/apps/tebcapture.html`, `/apps/tebintake.html` and `/apps/tebrounds.html` (two inbound links each); the homepage overview and globe now link all three.
- **Broken internal links.** One, in a noindex page: `tebcapture/index.html` links to `/dictate`, which does not exist on this site.

## 4. Homepage: content, keywords, structured data

Mechanism (so the next person does not undo it): `index.html` is the 3D tour. When WebGL and motion are available the script adds `html.j3d-on`, fixes `<main>` to the screen and shows one scene at a time by opacity. Without WebGL (or with reduced motion, or in a crawler that does not run WebGL) the same markup is an ordinary stacked page.

What changed:

- **New `#overview` section after `<main>`**: about 1,300 words of ordinary copy, one card per product (tebIQ, tebRounds, tebDictate, tebChart, IMG roadmap, free medical tools, tebIntake/tebCapture/Bellody, privacy), then 11 visible FAQ questions. In the static layout it is a normal section. While the 3D tour runs it is hidden and opens as a full-screen reading panel from `#overview` (links: hero line, footer list), closes with `#top`. It is not clipped text: a visitor can open and read it. No hidden keyword lists were added.
- **Terms covered in natural sentences**: AI medical scribe, ambient AI scribe, AI scribe for emergency medicine and for ER doctors, medical dictation app, free medical dictation, voice to text for doctors, nurse dictation, discharge instructions app, after visit summary, medication list, IMG roadmap, foreign medical graduate to U.S. residency, USMLE, ECFMG, OET, ERAS, the Match, hospitalist rounding, discharge summary, multilingual patient intake, free medical calculators (HEART, Wells, CURB-65, NEWS2).
- **Head**: title 61 characters, description 158, keywords meta rewritten (Google ignores it; it is harmless), Open Graph and Twitter fields aligned with the title and description, `og:image` and `twitter:image` added (they were missing).
- **JSON-LD**: one `@graph` with Organization (byte-identical to `products.html`, enforced by `tests/check-seo.mjs`), WebSite, WebPage (`@id` `https://tebscribe.com/#webpage`, `url` equal to the canonical), and the three SoftwareApplication nodes with the same `@id` values as `products.html`. - **Globe mount** inserted directly under the hero as specified (nine products in the requested order, distinct colors, external links tagged `utm_medium=globe`). In the 3D tour the hero moves to a left column and the globe takes the right column on desktop; on phones the hero is compacted and the globe sits above the Get started button. If `/assets/globe/*` returns 404 the list shows as a wrapped row of product chips (tested with the files removed). With the 3D script removed the page falls back to the static layout with the globe below the hero (tested).

## 5. International SEO (hreflang)

The site has a 12-locale script (`i18n-tebscribe.js`: English plus Spanish, French, Canadian French, Arabic, Persian, Hindi, Italian, Japanese, Portuguese, Russian, Chinese) and the shared menu has 11 more labels. The IMG page has its own 11-language switcher (`IMG/img-i18n.js`) that translates the page chrome only; the 10-part guide itself stays in English.

- **The locale variants are JavaScript-only, not URLs.** The language is chosen by `?lang=xx` or by `localStorage` and the text is swapped in the browser. Verified live: `https://tebscribe.com/?lang=es` returns the same HTML as `/`, with `<html lang="en">` and the canonical `https://tebscribe.com/`. There is no `hreflang` tag, no `x-default` and no alternate sitemap entry on any page (zero matches in the whole repo).
- **What that means.** Search engines see one English page per URL. The translations cannot rank or be returned for non-English searches, and a crawler that does not run JavaScript never sees them. It is not a duplicate-content problem, because the canonical consolidates every `?lang=` URL onto the English page. It is simply an unused opportunity.
- **If locale traffic is wanted**, each language needs a real URL (for example `/es/`) with a self-referencing canonical, fully translated visible content, and a reciprocal hreflang set with `x-default`. The dictionaries are marked "AI-drafted; native review owed", so publishing them as indexable pages now would risk thin or low-quality pages across the whole site. Recommendation: do native review first, then publish only the locales with real demand (Spanish, Persian, Arabic, Portuguese are the likely ones for this audience). Nothing was changed here because it needs new pages and a build step.

## 6. Core Web Vitals risks (read from the code; not measured)

Sizes on the homepage: `index.html` 73 KB (19 KB gzipped), of which 29 KB is inline CSS; `3d/tebscribe-3d.js` 527 KB (134 KB gzipped, deferred); `i18n-tebscribe.js` 101 KB (30 KB gzipped, a synchronous script at the end of `<body>`); `tb-nav.js` 17 KB (7 KB gzipped, a synchronous script in `<head>`, by design so the menu does not flash); the new globe adds `tb-globe.js` 19 KB (7 KB) and `tb-globe.css` 7 KB (2 KB).

- **LCP.** A full-screen "Entering tebScribe" loader covers the page until WebGL has rendered a few frames (`j3d-loader`), so the visible headline appears later than the HTML does. Field data is needed to say how much. The loader hides after about 0.9 s once frames render.
- **Render-blocking.** The Google Fonts stylesheet is render-blocking (one request to `fonts.googleapis.com`, then the font files from `fonts.gstatic.com`). The homepage also requested JetBrains Mono although no rule used it; removed. Inter is still requested in six weights (300 to 800); if the design uses three, drop the rest.
- **Dead CSS.** About two thirds of the homepage's class selectors (91 of 136) match nothing in the current body; they belong to the earlier classic homepage (`classic.html` is still in the repo). Removing them would cut roughly 20 KB of inline CSS. Not done: it needs a visual check of every scene and the classic page shares the styles.
- **INP.** The 3D loop runs on every frame and the tour keeps a second canvas now (the globe). On low-end phones that is the main risk; the globe module only draws while it is on screen (it uses an IntersectionObserver) and has a pause button.
- **CLS.** The hero and globe are absolutely positioned in the 3D mode, so no shift; in the static layout the globe section has a fixed minimum height from `tb-globe.css`. Low risk.
- **Images.** The only raster files are the 158 KB `og-image.png` (not loaded by pages) and two founder photos that only the noindex `classic.html` uses. No page has an `<img>` without alt.

## 7. Measurement and UTMs

- `tb-beacon.js` was missing on `products.html`, `bellody/privacy/` and `bellody/support/`; all three indexable pages now load it. It is absent from `404.html` and `tebcapture/` (both noindex) on purpose.
- `tb-consent.js` (GA4 `G-1XZK7XBL67`, loaded only after Accept, never with Global Privacy Control) is on all 22 pages, one include each (existing test).
- All 69 outbound links from indexable pages to tebiq.com, tebchart.com and tebdictate.com now carry `utm_source=tebscribe`, `utm_medium=<placement>`, `utm_campaign=<page slug>` and `utm_content=<product>`; the shared menu's "Try tebIQ" button builds its link at run time. The only exception is `tebiq.com/tebiqadmin` (a team sign-in, not product traffic). App Store and Play links cannot carry UTMs. The convention, ready-to-paste campaign links and where each kind of traffic is visible are in `docs/UTM-PLAYBOOK.md`.
- Important limit found while writing the playbook: the collector stores only `utm_source`, `utm_medium` and `utm_campaign`, tebchart.com and tebdictate.com static pages do not store campaign fields at all (CloudFront logs ignore the query string), and tebscribe.com page routes other than `/`, `/img` and `/3d` are recorded as `/other`. Details and file references are in the playbook.
