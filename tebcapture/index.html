      Help me

      The idea: your phone is the camera. This computer is where the video goes. The square code tells the phone which computer is yours.

      Code won't scan? Type the letters under it into the app. Same thing.

      Pressed Record and nothing happened? Look here. It should say Recording with a red dot. If not, check this window is open and the computer is online.

      Computer was asleep? Relax. The phone kept the video and sends it when you're back.

      Still stuck? Print the setup sheet and hand it to whoever helps you with computers. There is nothing on this page they can break.

      How to set up your computer for tebCapture

      Four steps. About two minutes. Do this once.

      1. Open this page on the computer: this web page, in Chrome or Edge.
      2. Choose a folder. Click the green “Choose a folder” button, pick Movies, click Allow.
      3. Show the code to your phone. Open tebCapture on the iPhone, tap Pair, point it at the square. Can't scan? Type the code under the square.
      4. Leave the window open. Press Record on the phone. The video saves itself into your folder.
      Computer asleep or offline? Nothing is lost. The phone keeps the video and sends it when the window is open again.
      Code expired? Click “Make a new code”. Nothing else changes.

      End-to-end encrypted between your phone and this computer. Encrypted in transit and at rest (AES). Never used for training. Never sold.
